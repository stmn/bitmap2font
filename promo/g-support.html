COLOR FONT MODE - WHERE IT RENDERS

Glyphs embedded as PNG bitmaps (CBDT + sbix tables) alongside regular vector outlines.

COLOR GLYPHS (baked AA + colors)

  • Chrome / Edge / Opera
  • Safari and macOS (Font Book, TextEdit...)
  • Godot and anything on FreeType
  • Windows (DirectWrite apps)

OUTLINE FALLBACK (plain vector shapes)

  • Firefox (reads only COLR format)
  • Unity TextMeshPro
  • stb_truetype-based engines
  • older design apps
The file always contains both. Renderers that do not understand color glyphs automatically use the vector fallback - text stays readable everywhere.
