HOW TO PREPARE YOUR SHEET

1Equal cells in a grid - one glyph per cell, no padding needed. Set columns x rows (or exact cell size) in the tool.
2Character order - left to right, top to bottom. Default is ASCII 32-126, starting with space.
3Background - transparent (alpha) or solid; ink vs background is detected automatically.
4Antialiasing / colors? Keep them - the Color font mode bakes them into the TTF.
Baseline = pixels from the cell bottom that hang below the text line.
Descenders of g j p q y live in that strip -
the tail of "g" dips below the amber line (here: cell 14x20, baseline 4).
Baseline 0 = glyphs sit on the cell bottom.
